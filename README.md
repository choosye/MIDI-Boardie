# MIDI-Keyboard
Half Life Hack Club Week 3 - MIDI Keypad

A custom MIDI Keypad to play around with music and have fun! Learning PCB design while making music come to life :D 

## Why? 
This project was created as part of Hack Club's Half Life Week 3 beginner tutorial to hone skills in PCB design. 
I wanted to learn more about PCB design by creating something interactive and music-related. This project is also an opportunity for me to explore how electronic components work together to create a functional MIDI controller!

## Project Status
The KiCad schematic and PCB layout have been designed, with slight customisations to make the keypad my own. The next steps are to manufacture the PCB and develop the firmware. 
The firmware will use KMK, a Python-based keyboard firmware framework. The project has not yet been tested on physical hardware, and further customisation and testing will happen as I continue learning :)
